# Pythagorean Theorem Game

An interactive game that lets students discover the Pythagorean theorem with a 3-4-5 right triangle.

Drag the small 1×1 squares from the two short sides (the 3×3 and 4×4 squares) into the big square on the hypotenuse, and see that they fill it exactly: 3² + 4² = 5².

- Drag and drop with magnet snapping, wobble and pooch sounds
- Every square is a little character with its own face and reactions (the name appears only while a square is held)
- Squares can be placed and mixed anywhere in the boxes; dropped outside the boxes they cry (Ms. Somia gets angry, Azad webs his way back)
- While Ms. Somia is held, the whole screen glitches into Arabic (and back when she is put down)
- **Auto fill** button, **characters on/off** button, sound on/off, start over
- Mobile first: always fits the screen, no scrolling
- Single file (`index.html`), no dependencies
